# Грабли и инсайты

Формат: дата → папка → проблема → решение → куда перенести.

---

## 2026-11-21 — `02-errors/validate_hosts`
**Грабли:** `netip.Is4()` возвращает `false` для `::ffff:192.168.1.1`.
**Решение:** Для строгих политик использовать `Is4()` + отдельно ловить `Is4In6()`.
**Перенос:** `sun-bng/internal/host` (строгая валидация для BNG).

---
## 2026-11-21 — `02-errors/session_vlan`
**Грабли:** `handleAuth` возвращала `(nil, nil)` при «мягкой» ошибке — вызывающий проверял только
`err != nil`, а первый же вызов метода на nil-сессии давал панику.
**Решение:** функция возвращает ошибку всегда; решение «WARN или падать» — политика вызывающего
(`main`/контроллер), не бизнес-логики.
**Перенос:** `sun-bng/internal/session` — при грязных данных от биллинга логировать и
продолжать, но контракт функции не менять.

---

## 2026-11-21 — `02-errors/session_vlan`
**Грабли:** дубль вывода: `HandleAuth` печатала WARN/OK внутри себя, а `testUser` печатал то же
самое — каждое событие отрабатывало дважды.
**Решение:** бизнес-функция не печатает ничего. Вывод, логи, метрики — только в контроллере
(`main`, HTTP-хендлер, worker).
**Перенос:** правило для всех модулей `sun-bng`: логгер никогда не внутри логики.

## 2026-11-21 — `02-errors/session_vlan`
**Грабли:** тест `TestHandleAuth` не проверял контракт «при ошибке сессия nil» и поле `ID`.
**Решение:** проверять весь контракт: `errors.Is(err, wantErr)`, `sess != nil` при ошибке,
`sess.ID` и `sess.VLAN()` при успехе. Бонус: `errors.Is(nil, nil) == true` — одно сравнение
покрывает оба исхода.
**Перенос:** шаблон table-driven теста для всех функций вида `(T, error)` в `sun-bng`.

## 2026-11-21 — `godummy` (организация кода)
**Грабли:** учебный монолит со всеми доменами в одном `main.go` невозможно запускать по частям.
**Решение:** резать по доменам: одна папка = один пакет, своя `main`, свои ошибки. Sentinel-ошибки
ездят со своим доменом, общий пакет ошибок — только когда появился второй потребитель.
**Перенос:** структура `internal/session`, `internal/host`, ... в `sun-bng` — по тому же принципу.
Имена файлов — от сущности (`host.go`), а не от глагола (`validate.go`).

## 2026-11-21 — `02-errors/validate_hosts`
**Грабли:** тест вызывал `IsStrictIPv4()`, а метод назывался `ParseStrictIPv4()` — имена должны
соответствовать возвращаемому типу: `Is*` → `bool`, `Parse*` → `(значение, error)`.
**Решение:** тест приведён к имени метода. В глазах новичка конвенция «честных имён» — первый
фильтр качества API.
**Перенос:** правило имён для всех новых API в `sun-bng`.

## 2026-11-21 — `02-errors` (теория, на будущее)
**Грабли:** sentinel-ошибка теряла деталь причины: оборачивали только `ErrInvalidIP`, а *почему*
строка не разобралась — из лога не видно.
**Решение:** с Go 1.20 можно оборачивать несколько ошибок: `fmt.Errorf("address %q: %w: %w",
h.IP, ErrInvalidIP, err)` — sentinel сохраняется, причина остаётся в сообщении.
**Перенос:** `sun-bng/internal/host` — трейс из логов сразу покажет источник грязной строки.
