## 2026-11-21 — `02-errors/validate_hosts`
**Грабли:** `netip.Is4()` возвращает `false` для `::ffff:192.168.1.1`.
**Решение:** Для строгих политик использовать `Is4()` + отдельно ловить `Is4In6()`.
**Перенос:** `sun-bng/internal/host` (строгая валидация для BNG).
